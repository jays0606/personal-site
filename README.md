# jaehoshin.com

Personal site of Jaeho Shin — a dated record of what shipped, from 2017 to now.

Next.js 16 · Tailwind v4 · MDX. Content lives in `content/record.ts` (the ledger) and
`content/work/*.mdx` (write-ups). See `CLAUDE.md` for structure and rules, and
`docs/plans/2026-09-05-the-record-design.md` for the design rationale.

```
npm install
npm run dev
```
